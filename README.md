# BenixSpace Super-App Monorepo Bundle

A comprehensive multi-application platform unified under a single architecture, shared Neon PostgreSQL database, universal authentication, central wallet ledger, multilingual capabilities, and Google Drive storage integration.

## Sub-Projects Included:
- **benixspace**: Core super-app frontend (React 19 / Vite / Tailwind) and backend (Node.js / Express).
- **tvapp**: Live TV channels, schedule guide, and on-demand video streaming.
- **radioapp**: 24/7 radio stations, live audio visualizer, and streaming.
- **voxify**: Choir management, song library, audio part practice, and sheet music marketplace.
- **kunda**: Dating and social community platform with feed, stories, and verified profiles.
- **market**: E-commerce marketplace with multi-vendor shop, checkout, and inventory management.
- **rollDice**: Interactive dice wagering mini-game integrated with central wallet.
- **benixEasyCalc**: Financial and scientific calculation utility tools.

## Unified Features
- **Dynamic Registration Wizard**: Context-aware onboarding based on selected apps.
- **Unified Dashboard**: Aggregated analytics, module controls, user management, and global platform settings.
- **Google Drive Storage**: Configurable OAuth2 refresh token storage service in Admin Settings.
- **Central Wallet**: Atomic ledger for wallet deposits, withdrawals, transfers, and game wagers.
- **Multilingual Engine**: Native support for English, Kinyarwanda, French, and Swahili.
- **Humanized Theming**: Dynamic theme switcher (Daylight, Dark, Midnight, Cyberpunk) with customizable accent colors.
